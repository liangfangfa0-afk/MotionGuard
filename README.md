# 晕动舒缓 MotionGuard

**本项目已停止维护（2026-11-25）。** 原因与后续说明见下方公告。

## 停止维护公告

这个项目停止更新。

这个应用的出发点很具体：不少机型出厂时并没有提供晕动舒缓（防晕车）能力，用户只能靠第三方应用把它补回来。

ColorOS 16 也是这种情况——系统本身没有提供晕动舒缓功能。现在有了第三方模块专门做这件事：在已 root 的设备上刷入该模块，缺失的能力就被补全，实测可以正常工作。模块的关键不在外形，而在底层——它把 OPPO 的两个私有传感器桥接成了 Android 标准传感器接口；桥一打通，原先只有系统内部能读到的运动数据，普通应用也能拿到。

同样是补全，从第三方 App 换成系统层模块，对使用者更直接：不依赖悬浮窗权限，也不受第三方应用的后台策略限制。因此这个项目没有再更新下去的必要。

项目停更是我的选择，不是所有设备的问题都已经被解决了：未 root 的设备用不了这个模块，仍然可以继续用这个应用。

到这里，这个项目最初想做的事已经有了另一种实现方式。至于最终是靠第三方模块补的，还是靠这个应用补的，只是手段不同。

**当前状态**

- 最后版本：**v1.94**（versionCode 194），最低 Android 14（API 34）
- 源码、构建说明与 v1.94 安装包保持可访问
- 不再发布新版本，不再修复已知问题，不再验证新系统兼容性
- 未 root 的设备仍可继续使用这个应用；已在 ColorOS 16 上 root 并刷入该第三方模块的设备，直接用模块提供的能力即可

**留下的东西**

- 传感器桥接这一结论，比应用本身更有价值：OPPO 私有传感器 → Android 标准传感器的可行性已被验证，这条路径可以复用到其他场景
- 界面层从液态玻璃迁移到 COUI-Kit 原生组件的取舍记录，保留在 v1.93 / v1.94 的变更说明里，包括为什么不继续跟进玻璃拟态

项目到此为止。代码还在，会一直留着。

## 简介

一款 Android 晕动舒缓辅助应用。通过运动传感器检测车辆运动状态，在悬浮层绘制与运动方向对应的反向光流气泡，帮助减轻视觉感受与身体前庭感受之间的冲突。

- 最后版本：**1.94**（versionCode 194）
- 应用包名：`com.ljj.yundongshuhuan`
- 最低系统版本：**Android 14（API 34）**
- 主要能力：双轴反向光流气泡、运动状态检测、姿态角显示、GPS / 网络定位信息面板、灵敏度与颜色设置
- 界面体系：COUI-Kit（ColorOS 17 设计语言），白色实体表面 + 浮岛导航，支持深色主题

## v1.94 更新

- 新增 COUI-Kit 原生深色主题与外观模式：跟随系统 / 浅色 / 深色，状态栏与导航栏图标自动反色
- 最低系统版本提升至 Android 14（API 34），不再维护 Android 12–13 的第二套导航实现
- 移除手绘底部导航回退 `PlainCouiNavigationBar`，底部导航统一使用 COUI-Kit 原生 `NavigationBar`
- 清理删除后不再使用的 import

## v1.93 界面变更

- 移除 `LiquidGlassBar`、`PrismalAGSL` 两个玻璃渲染子模块及其全部引用，应用内不再包含模糊、折射与半透明浮层
- 全局界面统一为 COUI-Kit / ColorOS 17 设计语言：背景、实体卡片、统一圆角与阴影层级
- 底部导航改为浮岛结构，使用 COUI-Kit 原生组件
- 灵敏度调节使用 COUI Slider：按压轨道扩展、弹性拖动、松手回弹
- 启动页移除 Material 3 渐变，改用 COUI 排版与字体
- 首次启动显示「设计更新」说明弹窗（COUI-Kit 原生对话框）
- 运动检测算法、传感器采样、GPS 定位与悬浮气泡逻辑均未改动
